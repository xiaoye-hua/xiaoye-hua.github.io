Notes

Reflexive — zich is not optional. It inflects: ik maak me, jij maakt je, hij maakt zich, wij maken ons. Commonest error is treating zich as invariant (ik maak zich zorgen ❌). Thing worried about takes over → questioning it gives waarover / split waar … over. hua typed maarkt; stem is maak, no r. Also in S2 les 3 part 2, s2: Maak je maar geen zorgen hoor — the 2nd-person imperative form maak je, which is exactly the inflection that gets flattened to zich. 2026-09-09 PRODUCTION EVIDENCE (s2): got the hard part right. hua wrote "Maak je maar geen zorg hoor" — the reflexive inflection maak je was correct, which is exactly the error I predicted above (flattening to zich). Only miss was the plural zorgen, which is obligatory in this chunk. Not upgraded to produced because the chunk was incomplete, but the reflexive is no longer the weak point.
